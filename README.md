# MDRU µXRF sample library

Teaching look-up site: pick a hand sample, find its deposit suite, open its micro-XRF element maps.
Built from Bruker M4 Tornado maps with MDRU's LightningXRF tools; each sample page is self-contained.
Element maps are X-ray window counts, not concentrations.
Contributors: Shaun Barker, Brian McNulty, Nelson Roman, Eduardo Fritis (MDRU, UBC).

Live site: https://sllbarker.github.io/mdru-uxrf-library/ · Printable QR labels: `labels.html`
